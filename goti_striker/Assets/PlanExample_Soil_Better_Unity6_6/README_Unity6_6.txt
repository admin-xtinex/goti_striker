BETTER LOOKING SOIL FOR UNITY 6.6
=================================
- Flat compacted dry soil surface
- Better looking 2K seamless top-down soil texture
- No pit openings
- Exact gameplay footprint kept the same

BEGINNER STEPS
1. Extract this package into Assets/.
2. Wait for import.
3. Drag PlanExample_Soil_Unity6_Better_LOD0.obj into the scene.
4. Select it in the Hierarchy.
5. Disable your TemporaryGround object in the Inspector checkbox.
6. Use Tools -> Goti Striker -> Setup Selected Soil (Unity 6.6 Better)
7. Keep Position 0,0,0 Rotation 0,0,0 Scale 1,1,1.
